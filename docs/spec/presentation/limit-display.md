# User-Facing Remaining Limit Display

This document defines the remaining-limit value shared by desktop and terminal presentations. It does not define bars, colors, widths, or placement.

The value represents available limit, not used limit.

Show the value as `{percentage}% left`, rounded to one decimal place. The same rounded value is used wherever the surface shows the remaining-limit percentage.

Examples:

```text
8.0% left
54.0% left
62.5% left
```
